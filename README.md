# Homebrew Tap

Custom Homebrew formulas.

## Installation

```bash
brew tap omar16100/tap
brew install batteryconsole
```

## Formulas

| Formula | Description |
|---------|-------------|
| batteryconsole | CLI tool to check Logitech MX device battery levels on macOS |
